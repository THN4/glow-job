Technology SVG logos are bundled locally from Devicon and Simple Icons.

- Devicon: https://github.com/devicons/devicon; MIT license in LICENSE.devicon.
- Simple Icons: https://github.com/simple-icons/simple-icons; CC0 in LICENSE.simple-icons.
- manifest.json records the pinned upstream revision/release, original file paths,
  and the database skill IDs assigned to each logo. Simple Icons SVGs use their
  upstream brand colors. Existing github.svg is retained from the original bundle.

Brand names and logos belong to their respective owners. Topic symbols are Lucide
icons; ambiguous names use initials, not an unrelated product's logo.

Refresh after exporting the skill catalog: `python scripts/prepare_skill_icons.py`
from the repository root. See docs/skills/README.md for export and validation.
